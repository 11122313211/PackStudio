# 塑胶工艺与公差说明

> **本文档是通用参考，标注"需厂商验证"的条目不得由本地直接下结论。**
> 塑胶件的尺寸、公差、外观与功能高度依赖材料牌号、模具、设备与工艺窗口。

## 1. 材料与表面附着力

- 常见材料：PP、PE、ABS、PC、PS、PET/PETG、PVC、HIPS。
- 塑胶表面能低，印刷、涂装、贴合前常需电晕、火焰或底涂处理。
- 透明材料（PETG、PS、PC）需关注透光率、雾度与耐黄变。
- **需厂商验证**：具体牌号、表面能数值、处理工艺与附着力测试结果。

## 2. 成型方式与公差

### 2.1 吸塑（Thermoform）

- 收缩率约 0.2%–1.0%，受片材牌号、加热温度与冷却速度影响。
- 深腔比通常约 1:1 以内；壁厚由片材厚度决定，成型后局部变薄。
- 公差一般 ±0.2–0.5 mm，需按材料与深度验证。
- 翘曲与回弹是常见问题，需通过模具冷却与脱模方式控制。

### 2.2 注塑（Injection）

- 收缩率约 0.3%–2.5%，必须按材料级数据（material data sheet）与实际
  壁厚确认，不能直接套用经验值。
- 公差一般 ±0.1–0.5 mm，精密件可更严；深筋与螺柱需更大脱模斜度。
- 壁厚突变会引起缩痕、气泡；流动长度受材料流动性限制。
- 翘曲可通过浇口位置、冷却系统、保压与退火改善。
- **需厂商验证**：首件尺寸、批次收缩率、外观缺陷接受标准。

### 2.3 吹塑（Blow mold）

- 收缩率约 1%–3%，型坯壁厚经吹胀后变薄，周向厚度分布需控制。
- 公差一般 ±0.5–2.0 mm；容量、口径、重量是关键功能尺寸。
- 瓶体需做容量、耐压、跌落与堆码验证。
- **需厂商验证**：容量、克重、壁厚分布、耐压与跌落测试。

## 3. 与纸 / 标签 / 内托的装配

- 塑胶与纸卡、纸盒的装配需考虑双方公差叠加，避免过紧或松动。
- 标签贴合需验证附着力与耐温/耐湿；曲面贴合需考虑拉伸变形。
- 内托与产品的间隙需按产品尺寸链计算，并做跌落测试。
- **需厂商验证**：装配间隙、标签附着力、跌落与运输振动测试。

## 4. 环保与合规

- 单塑/复塑包装的环保要求（如减塑、可回收、再生料比例）随地区法规变化。
- 与食品、儿童安全相关的应用有额外合规要求。
- **需厂商验证**：具体法规适用性、材料合规声明与第三方检测报告。

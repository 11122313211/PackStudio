# 烟包印后工艺与合规字段要求

> **本文档是通用参考，不是任何品牌或厂商的实测标准。**
> 所有工艺参数、尺寸、公差、防伪实现与合规字段布局，都必须以厂商的
> 实测数据和最终签样为准。文中出现 "需厂商验证" 的地方，表示该项不能
> 由本地推断或 LLM 生成直接判定。

## 1. CRD（冷烫金 / 压纹编码）

- **冷烫金原理**：先印 UV 胶水，再贴合冷烫膜，最后 UV 固化。与热烫相比
  没有金属压延层，亮度与耐摩擦性通常低于热烫。
- **适用范围**：适合细线条、大面积平铺、对亮度要求不极端的场景；不适合
  需要高金属质感的重点标识。
- **压纹编码**：把编码（流水号/批次码）压成可机读的凹凸纹理时，需保证
  编码位置、深度与扫描设备的识别阈值一致。
- **风险**：冷烫膜边缘翘起、胶水溢胶、编码压纹深度不均。
- **需厂商验证**：冷烫膜型号、胶水配方、固化能量、压纹深度与编码识别率。

## 2. 模压（压纹 / 击凸 / 压凹）

- **工艺类型**：整版压纹、局部击凸、压凹、模压编码。
- **关键变量**：模具材质（黄铜/镁/树脂）、压力、保压时间、纸板克重、
  含水量。
- **限制**：
  - 克重不足的纸板容易破裂或压塌；
  - 已覆膜材料需评估分层风险；
  - 压纹会改变表面摩擦系数，影响后续烫金/叠印附着。
- **需厂商验证**：模具寿命、压纹深度、纸板克重下限、叠印附着力。

## 3. 镭射（全息）

- **工艺**：镭射电化铝箔烫印，或镭射膜复合。
- **图案方向性**：镭射图案有方向，版面设计时需指定版号与方向。
- **限制**：大面积镭射易显脏、色偏；不同批次膜色可能有差异。
- **与防伪联动**：镭射常与拉线防伪、编码追溯配合使用。
- **需厂商验证**：膜版号、套印公差、批次色差、耐磨与附着力。

## 4. 拉线防伪

- **位置**：通常位于封签、条盒封口或内衬。
- **原理**：拉线与包装同步销毁（"一拉即毁"），防止二次封装。
- **实现要求**：
  - 拉线需与包装基材同色或可辨识；
  - 拉线断裂强度需高于正常开启需求，防止误断；
  - 拉线编码/序号需纳入追溯体系。
- **需厂商验证**：拉线断裂强度、胶水附着、编码唯一性与可读性。

## 5. 合规字段与安全区

### 5.1 警语区

- 健康警语（如"吸烟有害健康"）必须按法规规定的位置、字号、字体与
  背景对比度呈现。
- **不得**被任何工艺（烫金、UV、压纹）覆盖、压线或大幅降对比。
- 警语区需要保持完整可读，安全区内不允许出现折线、模切线。
- **需厂商验证**：具体法规版本、字号、警语措辞与背景色对比度（由法务确认）。

### 5.2 税费岛 / 税票区

- 税费岛是税务标签或税票的预留区域，需保持平整、可粘贴、不被工艺
  覆盖。
- 税费岛内的条码需满足识读要求，不得跨折线或压纹。
- **需厂商验证**：税费岛尺寸、位置、税票粘贴工艺与识读距离。

### 5.3 条码与追溯码

- 条码需满足可读性要求（对比度、留白区、条空尺寸公差）。
- 追溯码编码规则、数据关联（批次/流水号/生产日期）由业务方提供，
  本地不得编造。
- 条码/追溯码区域不得被工艺覆盖，安全区内需保留足够的留白。
- **需厂商验证**：条码等级、识读率、追溯码编码规则与数据接口。

### 5.4 安全区通用要求

- 文字、条码、追溯码、警语区均需避开折线（压痕线）、模切线与撕拉线。
- 出血位一般 ≥ 3 mm；安全边距一般 ≥ 3–5 mm（需按品牌规范确认）。
- 版面分色/分工艺时，需确认工艺层不会压到文字与码区。
- **需厂商验证**：出血、安全边距、模切公差、折线位置。
